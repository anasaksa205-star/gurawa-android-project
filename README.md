# Gurawa Woreda – Android app

Your HTML is at `www/index.html`, wrapped with Capacitor.

## Easiest: build online (no installs)
1. Create a free GitHub repo and upload everything in this folder (keep `.github/`).
2. Open the **Actions** tab -> **Build Android APK** -> Run workflow.
3. When it finishes (~5 min), download **gurawa-app-apk** -> `app-debug.apk`.
4. Copy to your phone and install (allow "install unknown apps").

## Or build locally
Install Node 18+, JDK 17, Android Studio/SDK, then run `./build.sh`.

## Changing the app
Edit `www/index.html`, then rebuild.
